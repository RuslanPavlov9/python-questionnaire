# Использованные промты

## Промт 1: Постановка задачи

> Вот есть такое Домашнее задание.
> Генерация простого приложения в IDE
>
> Цель:
> создать минимальное full-stack приложение (backend + frontend) с помощью AI-ассистента в IDE;
> настроить API для получения конфигурации анкеты и отправки ответов;
> научиться просить ассистента структурировать архитектуру и генерировать отдельные файлы;
> развернуть фронтенд, подключенный к backend API;
> реализовать хранение пользовательских ответов в памяти backend-приложения;
> проверить работу приложения локально;
>
> Требуемый функционал:
> Backend: GET /questions — список вопросов (3–5 шт.), POST /answers — приём и сохранение ответов в памяти
> Frontend: загрузка вопросов, отображение в HTML/JS, отправка ответов, сообщение «Спасибо!»
>
> Технологии: Python (FastAPI), чистый HTML+JS

## Промт 2: Запрос на создание backend

> Создай backend на FastAPI с двумя endpoint'ами:
> - GET /questions — возвращает 5 жёстко заданных вопросов анкеты
> - POST /answers — принимает ответы пользователя и сохраняет их в памяти (в list)
> Также добавь GET /answers для отладки и раздачу статических файлов фронтенда.

## Промт 3: Запрос на создание frontend

> Создай HTML/JS интерфейс анкеты:
> - Загружает вопросы с GET /questions
> - Отображает форму с валидацией обязательных полей
> - Отправляет ответы через POST /answers
> - Показывает сообщение «Спасибо!» после успешной отправки
> - Современный дизайн с CSS

## Промт 4: Запрос на тестирование

> Напиши тесты API с использованием FastAPI TestClient:
> - Проверка GET /questions (200, 5 вопросов)
> - Проверка POST /answers (200, статус ok)
> - Проверка сохранения в памяти через GET /answers
> - Проверка отдачи HTML-страницы
